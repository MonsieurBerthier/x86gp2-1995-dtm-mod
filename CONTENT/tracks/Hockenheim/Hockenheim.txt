  Work Process
   ..............

 the first version of this track was finished 3 weeks after the german
 Gp this year, and it contained a lot of new graphics in the original
 Microprose track. After that, I stopped working at this track and
 moved to another track, the Belgium one( which will be release).
 Then, I recieved over 100 e-mails concerning the Hockenheim 
 track I just made. To my surprise everybody liked the track and
 Wrongcliff pointed out there was a "great" sign where my track
 was loaded at Sjon's page. I felt very motivated to go 
 back and improve the track a bit more with so much encouragement
 from all of you. In the e-mails I recieved, not all were congratulating
 me; others suggested updates for other things and mostly to the 98
 layout. 
 For the new layout, I thought it would too much work until Obi Offiah
 came along to provide me with the beginning of what would be the 
 new layout for this track. I picked up his changes(90% were from him) and from
 others and started to edit the layout of the original Microprose
 94 track that I had put all the new graphics. 
 That part was very hard. At the same time I was working with that, I 
 was updating some textures for the version 1.0 of the track( to make 2.0)
 and leave the new layout for later as it was harder to make it and
 I was also working with Spa 98, and later on Monza 98.
 at the end of September I finished the layout and for the first 10
 days of october I worked with most possible realistic 98 camera positions
 . But there was bugs to be fixed before the releasing the track
 and I couldn't fix them. Once I sent the file to Adalberto Zaparoli!!!!!
 he promptly , and amazingly 'killed" the bugs , and because of him you all can
 have the final version so soon. I hope you all enjoy it.
 -----I hope this is the final version. I keep going back to this track always
maybe because it was the first one...now I added more graphical stuff and
positioned some textures at the places where they are in real life hockenheim.

  INSTALLATION
   ··············

ATTENTION: this is just an update , not a full file. YOU NEED
VERSION 3.0 OF MY HOCKENHEIM TO USE THIS TRACK PROPERLY!!!!!!!!

 First you need the GP2nocd patch for using any new tracks! It is 
 available at almost every homepage. You just have to run it to make 
 Gp2 read the tracks from the HD.
 extract the track file to the circuits directory and rename it to F1ct??.dat (tested only 
 in slot 09)

 Extract ALL the jams coming with this zip file into
 a the folder called HOC98. 

 
 Be sure to back up your old track file that has
 the same name as the new one you are adding on.
