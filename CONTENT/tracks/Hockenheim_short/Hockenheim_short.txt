Installation  :
---------------

1. Check whether you have a "CIRCUITS" subdirectory in your GP2-directory (HD).
   - If you don't have it:
     * Download and install No-CDROM, GP2NOCD or Tracks on HD utility
     * After installing you'll have the circuits directory
   - If you already have the directory:
     * No changes needed
2. Copy the SHORTHOC.DAT from the ZIP-packet to your CIRCUITS directory and rename
   it to overwrite an  existing track, eg. F1CT01.DAT=Slot #1, etc...
3. Create a subdirectory SHOCJAMS under the gp2\gamejams directory
4. Copy the *.JAD files and CONVERT.EXE to GP2\GAMEJAMS\SHOCJAMS directory
5. Go to GP2\GAMEJAMS\SHOCJAMS directory and execute CONVERT.EXE
6. Launch GP2 and have fun

About the Circuit  :
--------------------

This track is the '94 version of the Short Hockenheim circuit. The track
layout designed hasn't been changed since it.

The track is mainly used in the touring car races which explains why the
safety areas are so small.

Note! This track is NOT the propositional layout for the new Hockenheim
GP track.
