# x86gp2-1995-dtm-mod

A complete recreation of the 1995 German Touring Car Championship, 
or Deutsche Tourenwagen Meisterschaft (DTM) in German.

This mod transforms Grand Prix 2 into a 1995 DTM experience with
a complete championship, period correct touring cars and liveries, 
historically accurate tracks and race distances, custom driver 
performances and championship points.

## Installation

Merge the `CONTENT` folder with the one located in the x86GP2 Grand Prix 2 installation directory.

Additionally, if you also want to update the shadows beneath the cars, merge the `GAMEJAMS` folder 
with the one located in the Grand Prix 2 installation directory. 
It is recommended to make a backup of the `CSHAD1.JAM` file before merging.


## Limitations

Here are a few details that make this mod imperfect:

1. The cockpit is still the original one.

2. The steering wheel is still the original one.

3. The F1 wheels added by x86GP2 are still visible.

4. The helmets shown in the driver selection menu are still the two original ones.

5. The track names in the track selection menu are based on the country names, such as `Germany` or `Europe GP`.
